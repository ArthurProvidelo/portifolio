# `04 // FEATURED PROJECT`

<div align="center">

## 🐾 MobiPet

### Tecnologia aplicada a uma experiência mais inteligente para petshops.

</div>

O **MobiPet** é um projeto que integra software, banco de dados, aplicativo mobile e hardware para acompanhar o atendimento dos pets.

### ⚡ Fluxo do sistema

<div align="center">

```text
       🪪 RFID
          │
          ▼
    🔌 ESP32 + RC522
          │
          │  pet_id
          ▼
     ⚙️ API Laravel
          │
          ▼
       🗄️ MySQL
          │
          ▼
      📱 Flutter
          │
          ▼
     👤 Usuário
```

</div>

### Stack

`Flutter` · `Dart` · `Laravel` · `PHP` · `MySQL` · `ESP32` · `RFID`
